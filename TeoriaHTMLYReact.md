css en 3 renglones 
R\\CSS es un lenguaje para dar estilo a las páginas web.
Permite cambiar colores, tamaños, fuentes y posiciones.Se utiliza junto con HTML para crear páginas atractivas y ordenadas.

SELECTORES CSS 
R\\ Los selectores CSS sirven para seleccionar los elementos HTML que queremos modificar.
Algunos son: p (etiqueta), .clase (clase) y #id (identificador).
Permiten aplicar estilos específicos a diferentes elementos de una página web.

COMO UNA ETIQUETA PUEDE SER MODIFICADA POR MULTIPLES SELECTORES CSS
R\\Una etiqueta puede ser modificada por varios selectores CSS al mismo tiempo.
Los estilos se combinan según la especificidad y el orden de las reglas.
Por ejemplo, un <p> puede recibir estilos de p, .texto y #principal.
